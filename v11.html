  1. 行业断崖式下滑，2025Q4是分水岭。助贷新规2025年10月落地后，全行业2026H1营收同比下滑8%-61%，净利润下滑43%-94%（部分由盈转亏）。2025年全年微增主要靠上半年惯性，Q4新规落地后逾期跳升、拨备加码、放款收缩是真正拐点，2026年上半年进入深度调整期。
  2. 三梯队分化明确，头部与中腰部差距持续拉大。第一梯队（易鑫+13.3%逆势增长 / 奇富/信也/乐信-3%~-25%小幅下滑）；第二梯队（维信/小赢/嘉银/宜人-50%~-80%暴跌）；第三梯队（尾部出清）。头部凭轻资本转型+规模效应维持相对稳定，中腰部重资本模式承压明显。
  3. 利润跌幅远超营收跌幅，经营杠杆反向放大。奇富利润跌幅是营收的2.6倍，小赢近2倍，维信1.5倍。利率压缩+拨备增加双重挤压下，固定成本刚性使得利润端跌幅被放大，利润率越薄的机构放大效应越显著。
  4. 拨备是利润腰斩的头号杀手。头部机构拨备占营收20%-35%，亏损/微利机构高达60%-90%。拨备对利润跌幅的贡献分三档：头部机构30%-60%，中腰部机构50%-80%+，亏损机构主因是收入暴跌+风险释放，拨备是叠加项。拨备蓄水池越厚的机构，后续利润弹性越大。
  5. 轻重资本模式分化加剧，重资本阵营被动缩表。奇富、信也轻资本余额占比均突破50%，已从风险兜底转向科技服务，受新规冲击较小；小赢、嘉银、维信、宜人仍以重资本/担保模式为主，在利率压缩+风险上行的双重挤压下被动缩表，转型窗口期已非常有限。
  6. 资产质量Q1冲高Q2修复，但中长期逾期仍在恶化。M1/M2禁委外导致Q1短期逾期集体抬升，Q2自建内催到位后改善200-300bp。但中长期逾期仍在上行——维信M3+ 8.64%、小赢91-180天 9.09%、乐信90天+ 3.6%均创近年新高，存量不良尚未出清。
  7. 风险分层清晰：头部稳健、中腰部承压、尾部出清。奇富/信也拨备充足、轻资本过半，大概率可穿越周期；乐信/小赢/嘉银/维信/宜人规模收缩+拨备压力大，经营可持续性承压；非上市尾部平台或加速出清。

业务结构总览分析：

  • 第一层（头部平台：奇富+信也）：轻资本过半+出海对冲。两大头部平台轻资本模式占比均已突破50%，从"赚利差/担保费"转向"赚技术服务费"，抗周期能力显著更强。信也科技凭借27%的海外收入占比形成独特的双轮驱动。
  • 第二层（中间梯队：乐信+陆金所）：信贷为主+重资本自营。乐信所谓"分期电商"实质为无实物现金分期，多元对冲成色有限。陆金所则背靠平安体系走重资本自营路线。
  • 第三层（中小机构：小赢+嘉银+维信+宜人）：重资本被动缩表。普遍仍以重资本/担保模式为主，在利率压缩+风险上行的双重挤压下被动缩表。
  • 独立赛道（易鑫）：汽车金融独苗。以车辆抵押品的天然风控优势+SaaS平台化转型走出了独立行情。

放款端的收缩节奏在中腰部机构尤为剧烈，除了利率红线导致的风险收益失衡外，运营商管控政策也是重要推手——2026年以来短信同意制（5月1日施行）、外呼白名单新规（7月落地）及金融产品网络营销办法（9月30日实施）相继落地，传统短信/外呼获客渠道的触达效率显著下降、获客成本明显抬升。中腰部机构对线上直客渠道依赖度更高，品牌引流能力弱于头部，受冲击更大，进一步加剧了放款量的收缩速度。

拨备蓄水池分层（精简）

拨备加码的政策驱动因素：本轮拨备普遍加码的核心驱动并非单纯的经济周期波动，而是催收监管与扫黑除恶的双重挤压。2026年春节前后，M1/M2逾期阶段不得委外催收的窗口指导率先落地，直接导致短期催收效率下降、回收率走低；叠加扫黑除恶常态化对"软暴力"催收、非法讨债的持续高压打击（2026年8月地方调度进一步加码），催收行业整体处于"合规监管+扫黑打击"的双重约束之下。催收效率下降→不良回收率走低→不良率上行→拨备加码，这一传导链条在上半年已清晰显现，也是利润端跌幅被进一步放大的关键政策变量。深层影响逻辑详见第三章3.1节。

资产质量走势的政策解读：Q1短期逾期集体冲高、Q2普遍回落200-300bp的走势，与M1/M2禁委外窗口指导的冲击节奏高度吻合。春节前后禁委外政策落地初期，各机构委外催收渠道突然中断，而自建内催团队尚未到位，导致M1/M2阶段的逾期回款率显著下降，短期逾期率被动跳升。进入Q2后，多数头部机构的自建内催团队逐步到位、催收产能恢复，短期逾期随之明显修复。但需注意的是，这一修复主要集中在短期逾期维度，中长期逾期（M3+）仍在持续恶化（维信M3+ 8.64%、乐信90天+ 3.6%均处高位），说明存量不良的深度出清尚未完成，催收受限对中长期资产质量的影响仍在持续释放。

1.4 关键发现

  1. 利润跌幅远超营收跌幅，拨备是核心放大器。营收下滑8%-61%的同时，利润下滑43%-94%，跌幅普遍放大1.5-23倍。拨备占营收比从头部的20%-35%到亏损机构的60%-90%，分化悬殊——拨备蓄水池越厚的机构，后续利润弹性越大。
  2. 头部vs中腰部分化加剧，模式差异是核心解释变量。第一梯队（易鑫逆势增长 / 奇富/信也/乐信小幅下滑）的共同特征是轻资本过半或有垂直赛道护城河；第二梯队（维信/小赢/嘉银/宜人暴跌）均以重资本/担保模式为主。轻资本占比、资金端能力、出海进展三大变量的交叉组合，决定了各机构的抗周期能力。
  3. 短期逾期修复但中长期仍在恶化，存量风险尚未出清。M1/M2禁委外导致Q1短期逾期集体抬升，Q2自建内催到位后改善200-300bp。但维信M3+ 8.64%、小赢91-180天 9.09%、乐信90天+ 3.6%均处于高位，存量不良消化仍需时间。

扫黑除恶对行业的深层影响（当下环境演化判断）

全国扫黑除恶常态化持续推进，叠加M1/M2禁委外窗口指导，催收行业正面临"合规监管+扫黑打击"双重挤压。对助贷行业的影响远不止催收成本上升，而是从风险成本、防线体系、资金供给、商业模式到监管预期的全方位冲击：

  1. 风险成本中枢抬升：催收受限→回收率下降→不良率攀升→拨备加码→利润承压。不是催收成本那点钱的问题，是整个风险成本曲线往上移——原来100块贷款的风险成本可能是3块，催收受限后可能变成5-6块，利润率直接被吃掉一半甚至更多。
  2. 第二道防线被削弱：助贷行业靠"风控+催收"两道防线。催收受限后，第二道防线作用大幅削弱，所有压力都压到第一道。但24%以下客群的风控有物理极限——你不可能把所有人都拦在门外，否则业务就不用做了。
  3. 资金端传导：银行、消金公司等资金方会重新评估助贷资产的风险收益比。风险收益比变差了，资金就会向头部机构集中，中腰部机构的资金合作难度会加大。
  4. 模式倒逼：从重资本赚风险钱→被迫转轻资本赚服务钱。但轻资本的Take Rate本身就低，规模又在收缩，也不好赚。
  5. 信号意义：监管容忍度持续下降，行业需要把"催收受限"作为长期假设来做业务规划和盈利模型。

暴雷风险指标（与现金流/担保杠杆联动）

  • 担保/增信余额 vs 净资产（杠杆率）：中腰部机构的担保余额往往是净资产的5-10倍，杠杆极高。不良率每上升1个百分点，净资产就可能少10%以上。
  • 经营活动现金流：现金代偿是实打实的现金流出。如果经营活动现金流持续为负，同时融资现金流在收缩，就是双重失血，流动性风险会快速累积。
  • 资金方集中度：前三大资金方占比超60%、且以中小银行为主的机构，撤资风险高。一旦某家资金方因为风险担忧而抽贷，可能引发连锁反应。

资金方收回资产：中腰部机构如果兜底能力下降，资金方（消金/农商行/地方城商行）可能会主动收回资产自行处置，加速行业出清。

盈利视角补充：24%红线下的成本结构

对余额规模200亿及以下的中腰部助贷平台，按24%综合融资成本倒推成本结构，行业普遍面临盈利困境：

成本项典型区间说明
资金成本8-12%中腰部机构资金成本显著高于头部（头部6-8%）
获客成本5-8%依赖短信/外呼渠道，运营商管控后成本上升
运营成本2-3%信审、客服、系统、税费等
风险成本3-5%（正常）→ 6%+（催收受限后）催收效率下降直接推高风险成本
合计18-28%24%天花板下利润极薄甚至为负

头部平台凭借规模效应（获客成本低2-3pct）、资金端议价能力（资金成本低1-2pct）和多元化收入（轻资本服务费、海外利润）勉强能打平甚至盈利，但中腰部平台单一渠道+高风险成本+弱资金能力的组合在24%红线下几乎无解。

催收受限后的恶化路径：催收受限 → 回收率下降 → 风险成本升至6%+ → 突破24%红线 → 主动缩表 → 固定成本摊薄效应消失 → 亏损扩大 → 现金流承压 → 资金方抽贷 → 加速出清
